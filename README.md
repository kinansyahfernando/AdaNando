# AdaNando

Ujian sekolah & Try Out UTBK online — penilaian di server, anti-curang berlapis, panel guru web, aplikasi siswa untuk web/PWA (laptop, iPhone, Android) dan APK.

Mulai dari **[PANDUAN.md](PANDUAN.md)**.

- `backend/` — API Node.js/Express + MySQL, panel guru di `backend/public/admin`
- `frontend/` — aplikasi siswa Flutter (web/PWA, Android, iOS, Windows)
